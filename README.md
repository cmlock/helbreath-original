# Helbreath Server 3.82 (Visual Studio 2026 recommended)

- Client 3.82 default with 800x600 resolution and Windows 10/11 compatibility.
- HGServer 2.24b modified to work with the client resolution.
- HB Server Files 3.51 (2.25a) with default configs and maps.
- Helbreath USA 3.72 installer

## Repository Structure

- [`Client/`](Client/README.md) — Win32 game client source (Visual Studio project).
- [`HGServer/`](HGServer/README.md) — game server source (Visual Studio project).
- [`Files/`](Files/README.md) — deployable server runtime: executables, configs, and per-zone data.
- [`Helbreath/`](Helbreath/README.md) — client game assets: sprites, maps, sounds, music, fonts.
- [`Tools/`](Tools/README.md) — third-party editor and admin tool archives.
- `CONTENTS/`, `SPRITES/` — legacy loose asset files kept at the repo root.
