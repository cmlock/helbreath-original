# Monster Spawn Audit vs. Helbreath Nemesis

Tracks reconciliation of this repo's monster spawn tables against [helbreathnemesis.com/portal/monsters](https://www.helbreathnemesis.com/portal/monsters), a reference server the project considers well-tuned. Drop tables are captured here for a later phase but not yet edited (they live in scattered `switch(m_sType)` blocks in `HGServer/Game.cpp`, e.g. `NpcDeadItemGenerator` ~line 48078 — C++ + rebuild, not a data-only fix).

**Process, statuses, and scope rules:** see the approved plan (or re-derive: alphabetical by this repo's `NPC.cfg` name; cross-reference `spot-mob-generator`/`random-mob-generator` entries in `Files/GameServers/*/MAPDATA/*.txt` against the switch tables in `Game.cpp`; fix only clear mis-keyed/dead entries directly; flag anything needing invented data or a code change rather than guessing).

Status legend: `not-started` / `researched` / `fixed` / `flagged` (needs a decision or a code change) / `skipped` (out of scope).

## Out of scope (not tracked row-by-row)

- **Crusade structures/summons**: AGT, CGT, MS/ManaStone, DT, ESG, GMG, LWB, GHK, GHKABS, TK, BG, CP, XB/XW/XY/YB/YW/YY-Aresden/Elvine — not creatures.
- **Heldenian war-summon units**: Sor(Sorceress)/ATK(Ancient Temple Knight)/Elf/DSK(Dark Knight)/HBT(Battle Tank)/CT(Crossbow Turret)/Bar(Barbarian)/AGC(Ancient Cannon)-Aresden/Elvine. Confirmed via `Game.cpp:43079-43133` — these are player-triggered "Request Summon War Unit" constructs (same mechanism as the Crusade structures above), not wild spawns. `GodH.txt`/`HRampart.txt`/`BtField.txt` (the 3 Heldenian maps) have zero `spot-mob-generator`/`random-mob-generator` data — the only NPCs those maps place directly are the `CT`(87)/`AGC`(89) siege towers via `HeldenianTower` lines and the `gate-a`/`gate-e`(91) doors via `HeldenianGateDoor`, both handled by dedicated code, not the generic mob-generator system. No "spawn location" bug to chase here regardless of what Nemesis's own server does with them.
- **Nemesis-only content absent from this repo's `NPC.cfg`**: Dragonia monsters (Earth/Illusion/Lightning/Poison/Black Dragon), Goblin, Lava Golem, Twin Mage, Twin Warrior.
- **Nemesis map names with no corresponding file in this repo** (recurring across multiple monsters — likely zones Nemesis added that this older codebase snapshot never had): Promise Land, Promiseland Dungeon, Eternal Field, Rocky Highland, Death Valley, Aresien's Garden, Eldeniel's Garden, Silent Woods. Confirmed via Nemesis's own `/portal/maps` index (which assigns these real map IDs, e.g. Promise Land=4) cross-checked against `Glob`'d contents of `Files/GameServers/*/MAPDATA/` — no matching `.txt` file exists for any of them. Treat any monster's "missing" location as **not a bug** if it's one of these names; don't invent a file for it.
